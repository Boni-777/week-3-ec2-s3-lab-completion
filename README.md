# Week 3: EC2 and S3

This week, I completed the AWS Skill Builder courses **Introduction to Amazon EC2** and **Introduction to Amazon S3**, along with their hands-on lab activities.

### What I Completed

**1. Amazon EC2**

* Learned how to launch and configure EC2 instances.
* Configured security groups and networking.
* Connected to an EC2 instance using AWS Systems Manager (SSM).
* Explored IAM roles and instance permissions.

**2. Amazon S3**

* Created and managed an S3 bucket.
* Uploaded and accessed objects.
* Explored object permissions and bucket policies.
* Configured EC2-to-S3 access using IAM roles.
* Enabled bucket versioning.
* Practiced viewing previous versions, deleting objects, and recovering deleted files.

### Certificates I have gained

* Introduction to Amazon EC2
* Introduction to Amazon S3
  They are found in the certificates folder of the github repo.

### Key Takeaway

This week's activities gave me practical experience with AWS compute and storage services, cloud security, access management, and data protection.
